# Agentic Genealogy Models

This directory contains Modelfiles for specialized agentic genealogy assistants. These models have system prompts that encode the tool-calling protocol, error recovery patterns, and domain-specific workflows.

## Models

### 1. `gene-chat-fast-agent` (Llama 3.1 8B)

**Best for:** Quick lookups, simple queries, single-person biographical questions

- **Base model:** `llama3.1:8b`
- **Context window:** 16K tokens
- **Temperature:** 0.3 (focused but not rigid)
- **Expected tool calls:** 1-3 per query

**Use cases:**
- "Tell me about Pieter van Zanten"
- "When was Bessel born?"
- "Who were Aart's parents?"

### 2. `gene-chat-main-agent` (Qwen2.5 14B) ⭐ Default

**Best for:** Standard agentic queries, relationship tracing, family reconstruction

- **Base model:** `qwen2.5:14b-instruct-q5_K_M`
- **Context window:** 32K tokens
- **Temperature:** 0.1 (very focused, minimal creativity)
- **Expected tool calls:** 2-6 per query

**Use cases:**
- "How are Eugene and Pieter van Zanten related?"
- "Tell me about the van Zanten family in Naarden"
- "Find all railway workers in the database"

### 3. `gene-reasoner-agent` (DeepSeek-R1 14B)

**Best for:** Complex reasoning, identity merging, conflicting records

- **Base model:** `deepseek-r1:14b`
- **Context window:** 32K tokens
- **Temperature:** 0.2 (very deterministic)
- **Expected tool calls:** 4-10 per query
- **Special feature:** Shows thinking process in `<think>` tags

**Use cases:**
- "Are these two Bessel van Zantens the same person?"
- "Trace the family line from Aart (V.1) to his descendants in America"
- "Reconcile these conflicting birth records for Pieter"

## Installation

Build all three models:

```bash
cd modelfiles

# Fast agent (for quick queries)
ollama create gene-chat-fast-agent -f gene-chat-fast-agent.Modelfile

# Main agent (default for most queries)
ollama create gene-chat-main-agent -f gene-chat-main-agent.Modelfile

# Reasoning agent (for complex problems)
ollama create gene-reasoner-agent -f gene-reasoner-agent.Modelfile
```

Verify installation:

```bash
ollama list | grep gene-chat
```

You should see:
```
gene-chat-fast-agent    ...
gene-chat-main-agent    ...
gene-reasoner-agent     ...
```

## Quick Test

Test the main agent:

```bash
ollama run gene-chat-main-agent
```

Then try a query that requires tool calling:
```
How would I find information about someone named "van Zanten"?
```

The model should explain the workflow: search by name first, then use the ID from results for detailed queries.

## Architecture

### System Prompt vs Dynamic Prompt

**System Prompt (in Modelfile):**
- Tool calling protocol (TOOL_CALL/ARGUMENTS/REASONING format)
- Error recovery patterns (duplicate calls, ID extraction, etc.)
- Required workflows (relationships, biographies, family queries)
- Response style guidelines
- Domain expertise (Dutch names, patronymics, etc.)

**Dynamic Prompt (generated by `agent_executor.py`):**
- Current user query
- Available tools
- Previous tool calls and results
- Current context/conversation history
- Iteration count

This separation means:
1. ✅ Shorter prompts (less token usage)
2. ✅ More consistent behavior (system prompt always applies)
3. ✅ Easier to debug (change system prompt = rebuild model once)
4. ✅ Less repetition and confusion

### Key Improvements Over Previous Approach

**Before:** The `_build_agent_prompt()` method contained ~100 lines of instructions, including:
- Tool protocol explanation
- Error handling examples
- Workflow specifications
- Response format examples

This was sent with **every iteration**, causing:
- High token usage
- Potential confusion from repetition
- Conflicts with base model's system prompt

**After:** System prompt contains invariant instructions, dynamic prompt is ~18 lines:
- User query
- Available tools
- Previous calls
- Current context
- Simple reminders

## Usage in Code

Update `agent_executor.py` to use the new models:

```python
class AgentExecutor:
    def __init__(self, model: str = "gene-chat-main-agent", ...):
        # Default to the main agent model
        self.model = model
        ...
```

For complex queries, route to the reasoning agent:

```python
# In your routing logic
if is_complex_reasoning_query(query):
    executor = AgentExecutor(model="gene-reasoner-agent")
elif is_simple_lookup(query):
    executor = AgentExecutor(model="gene-chat-fast-agent")
else:
    executor = AgentExecutor(model="gene-chat-main-agent")
```

## Troubleshooting

### Model not found
```bash
ollama list | grep gene-chat
# If missing, rebuild with ollama create
```

### Wrong behavior
1. Check which model is being used: `agent_executor.py` line 80
2. Test the model directly: `ollama run gene-chat-main-agent`
3. Verify the system prompt in the Modelfile matches your expectations

### High error rates
- Check iteration logs to see which tool calls are failing
- Verify ID extraction from search results
- Consider using `gene-reasoner-agent` for complex queries
